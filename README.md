# Finance Ease

Um aplicativo web simples para controle financeiro pessoal, desenvolvido por Carlos Piquet.

## Funcionalidades

- Adicionar receitas e despesas
- Categorizar transações
- Visualizar saldo atual
- Filtrar transações por mês, tipo e categoria
- Editar e excluir transações
- Armazenamento local (localStorage)

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- LocalStorage para persistência de dados

## Como Usar

1. Acesse a aplicação em: [https://carlospiquet2023.github.io/finance_ease/](https://carlospiquet2023.github.io/finance_ease/)
2. Adicione suas transações usando o formulário
3. Visualize seu saldo e histórico de transações
4. Use os filtros para encontrar transações específicas

## Desenvolvimento

Este projeto foi desenvolvido como uma aplicação web simples, sem dependências externas. Todos os dados são armazenados localmente no navegador do usuário através do localStorage.
